فعال‌سازی نگارش و خواندن نامه

این صفحه برای به‌روزرسانی سرویس موجود Cloudflare است. قبل از تغییر، از کد فعلی Worker نسخه نگه دار. سرویس تبدیل صدا و مسیرهای موجود را حفظ کن.

۱. فایل زیر را با نام writing.mjs به Worker اضافه کن؛ از کلید رمزگذاری‌شدهٔ موجود GROQ_API_KEY استفاده می‌کند.

۲. این import را به بالای فایل اصلی اضافه کن:

import { writing, correspondenceOCR } from './writing.mjs';

۳. این دو مسیر را داخل همان تابع رسیدگی به درخواست‌ها، بعد از کنترل‌های دسترسی فعلی و قبل از پاسخ not_found قرار بده. سپس Deploy کن.
